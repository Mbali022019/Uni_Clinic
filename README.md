
# University Clinic Management System

## Project Overview
The University Clinic Management System is a web-based system designed to improve the management of university clinic services. The system helps reduce long queues, overcrowding, and manual filing processes by introducing an online appointment booking system with sensor-based student card scanning.

## Problem Statement
University clinics often experience long waiting queues, overcrowding, and inefficient manual record management. These challenges create delays for students and increase workload for clinic staff.

## Proposed Solution
This project introduces a smart clinic management system where students can:
- Book clinic appointments online
- View available booking slots
- Check appointment status
- Use student card scanning for appointment validation

The system will also enforce daily booking limits to avoid overcrowding in the clinic.

## Main Features
- Student registration and login
- Online appointment booking
- Appointment slot management
- Sensor/card scan validation
- Patient record management
- Dashboard and analytics
